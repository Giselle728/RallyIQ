Pipeline Architecture

1. Data Ingestion & Schema Validation: Real Match Charting Project datasets downloaded directly from Jeff Sackmann's repository. Deduplication, type validation, and missing value profiling.
2. Distributed Batch Processing (PySpark): Aggregations across 900,000+ points and 7,500+ matches using PySpark DataFrames and Spark SQL on local JVM executors.
3. Storage Layer (MongoDB): Document collections for matches and player profiles, with compound indexes.
4. Analytics & Algorithms: Supervised Random Forest Classifier, PageRank centrality, Louvain Community Detection, and Cosine Playstyle Recommender.

Graph Algorithm Formulation

Louvain Algorithm: Maximizes modularity Q by iteratively moving nodes to neighbor communities that yield maximum modularity gain, then building a new network whose vertices are communities.

PageRank: Measures eigenvector centrality across directed match edges with damping factor α = 0.85.
